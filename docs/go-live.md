# Going live: where every credential and address goes

Three files, none of them committed. Check everything afterwards with the commands at the end.

## 1. `.env` (project root): secrets

One `NAME=value` per line, no quotes, no spaces.

| Name | For | Where to get it | Status on this Mac |
|---|---|---|---|
| `DEEPGRAM_API_KEY` | Speech to text and the spoken voice, in the headphones and on phone calls | Deepgram console | set |
| `OLLAMA_API_KEY` | The voice agent, the phone-call agent, and OpenClaw's writing | ollama.com/settings/keys | set |
| `TWILIO_ACCOUNT_SID` | Phone calls to the caregiver | Twilio console, Account Info | set |
| `TWILIO_AUTH_TOKEN` | Phone calls | Twilio console, Account Info | set |
| `TWILIO_FROM_NUMBER` | The number the caregiver sees calling, like `+14155550100` | A voice-capable number bought on that Twilio account | set |
| `STEADY_SMTP_PASSWORD` | Email: your mail account's **app password** (not your normal password) | Your mail provider (Gmail: Google Account, Security, App passwords) | **to add** |
| `STEADY_API_TOKEN` | OpenClaw to Steady | generated by `steady openclaw setup` | set |
| `OPENCLAW_HOOK_TOKEN` | Steady to OpenClaw | generated by `steady openclaw setup` | set |

## 2. `config/contacts.yaml`: who you are and who may be reached

Copy `config/contacts.example.yaml` if you start again. This file is the allowlist: nobody
outside it can ever receive a text, an email or a call. Phone numbers in full form, `+14155550123`.

```yaml
sender:
  name: Akshay                  # how messages and calls refer to you
  phone: "+1..."                # your own iMessage number
  email: you@example.com        # every email is sent From this address

smtp:                           # your mail account (the password goes in .env, not here)
  host: smtp.gmail.com
  port: 587
  username: you@example.com
  security: starttls            # starttls (587) or ssl (465)

contacts:
  caregiver:                    # texts, the end-of-day brief, and the FIRST phone call after a fall
    name: Priya
    phone: "+1..."
    email: priya@example.com
  backup_caregiver:             # optional: phoned if the caregiver does not confirm
    name: Sam
    phone: "+1..."
  doctor:
    name: Dr. Patel
    email: patel@clinic.example
```

**The file on this Mac holds fake test values.** Replace them before going live.

## 3. `config/local.yaml`: this Mac's switches

```yaml
delivery:
  mode: live        # dry_run (now): texts and emails go to data/outbox.jsonl and nobody is phoned
band:
  transport: ble    # ble (Bluetooth) or serial (USB cable)
```

Leave the `openclaw:` block as `steady openclaw setup` wrote it.

## What each path needs

| Path | Needs |
|---|---|
| Voice in the headphones | `DEEPGRAM_API_KEY`, `OLLAMA_API_KEY`, headphones connected |
| Text message (iMessage) | Messages on this Mac signed in to your iMessage account; `sender.phone`; the contact's `phone`; `delivery.mode: live`; the OpenClaw gateway running. The first send makes macOS ask whether your terminal may control Messages: allow it |
| Email | `smtp` block, `STEADY_SMTP_PASSWORD`, `sender.email`, the contact's `email`, `delivery.mode: live`, the OpenClaw gateway running |
| End-of-day brief | As for a text and/or an email (`brief.via` in `config/steady.yaml`), to `brief.to` |
| Phone call after a fall | The three `TWILIO_*` values, the caregiver's `phone`, `cloudflared` installed, `delivery.mode: live`, a real band (the pretend band never phones) |

## Costs and limits to know

- A Twilio **trial** account only calls numbers you verified and plays a trial notice first.
  `steady doctor` says whether the account is a trial.
- The call's public address is a new `cloudflared` quick tunnel on every start, so nothing
  needs configuring; it takes about 10 seconds to come up.
- A text only reaches someone who uses iMessage, unless your iPhone forwards SMS to this Mac.

## The demo, start to finish

Two terminal tabs (macOS Terminal, or the Terminal pane in the Claude app):

```bash
PYTHONPATH=src .venv/bin/python -m steady openclaw gateway --profile steadytest --port 19789
PYTHONPATH=src .venv/bin/python -m steady run --demo
```

`delivery.mode` must be `live` in `config/local.yaml`, or nobody is phoned and nothing is sent.

1. Rest your forearm and shake only the hand, about 5 times a second, for 15 to 20 seconds.
   Steady speaks first: what it noticed, and an offer of help. Say you are fine; it ends.
2. Wait about 30 seconds. Shake again the same way. Say nothing. Steady asks, waits 12 seconds,
   asks once more, waits 12 seconds, then says it is phoning the caregiver.
3. The caregiver's phone rings from the Twilio number. Steady speaks first and cannot be
   interrupted; then it is a conversation of up to 3 minutes. Saying yes (or pressing 1) confirms.
4. A text and an email go to the caregiver, and Steady says so in the headphones.

The whole thing without a band, to rehearse (the pretend band plays the tremor):

```bash
PYTHONPATH=src .venv/bin/python -m steady.validate.demo           # dry run
PYTHONPATH=src .venv/bin/python -m steady.validate.demo --live    # real call, text and email
```
